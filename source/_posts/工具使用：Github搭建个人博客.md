#### 2.3 初始化Hexo

> 备注：这里我手动操作，但我相信，workbuddy设置好工作目录，然后你说：在当前路径下，使用hexo创建一个名为xxx的博客网站。它一定会帮你创建好

​	第一步，进入到你想要放置博客网站的目录，然后打开命令行窗口。

​	第二步，执行下面的命令：

```python
# 在当前目录下，创建并初始化My_Blog文件夹，这个名字随便定义，建议使用英文
hexo init My_Blog

cd My_Blog

# 安装依赖
npm install 
```

​	第三步，前面完成后，启动一下看看：

```

```

#### 3.1 更新/新建文章

​	**说明：必须在博客网站文件夹下使用命令才可识别。**

```python
# 1. 写新文章
hexo new "文章标题"
# 编辑 source/_posts/xxx.md

# 2. 提交并推送（GitHub 会自动构建发布）
git add -A  # 保存更改
git commit -m "新文章"   # -m后面的是说明内容
git push  # 更新
```

#### 3.2 删除文章

- 打开 `source/_posts/` 文件夹
- 找到要删的文章文件（`.md` 文件），直接删除
- 提交并推送，让线上同步：

```python
git add -A
git commit -m "删除文章：xxx"
git push
```

#### 3.3 带图片的文章怎么处理

​	需要**开启资源文件夹功能**，这样会自动创建目录，比如：

```python
source/_posts/
├── 我的文章.md
└── 我的文章/          # 自动创建的同名文件夹，图片放这里
    └── 图片.png
```

​	开启方法：使用AI，提示词为：

```
网站需要开启资源文件夹功能，实现图片文件夹的自动创建
```

#### 3.4 关于标签和分类

​	现在创建新的文章，md文件的头部会有下面的内容；

```python
---
title: 示例文章：我的第一篇技术笔记
date: 2026-10-12 11:13:00
categories:          # 分类：层级结构，缩进表示父子
  - 技术笔记
  - Hexo
tags:                # 标签：并列结构，可多个
  - Hexo
  - 博客
  - 教程
---
```

​	自己手动修改即可实现标签和分类。

#### 3.5 安全问题解答

1. 我把整个文件夹都上传到GitHub上了，是否存在风险，比如那个GitHub密钥是否会暴露，是否存在账号被盗风险？

答：没有风险

2. 我把东西都上传到GitHub上了，要是别人把整个项目都下载本地，是不是拥有了我的一切？然后别人可以通过这些去上传文章吗，还是只有我才可以？

答：博客本身是公开的；推送文章是账号权限，别人无法向里面推送，除非我给别人开放权限。
