# AI代理模型：从仿真加速到数据质量与泛化验证

## 1. 前言

​	做仿真时，一个比较直接的问题是：模型能够算出结果，但算得太慢。如果只是分析几个工况，还可以等；如果需要反复调整参数、寻找较优方案，计算成本就会成为限制。

​	那么，能不能先用仿真生成一批数据，再训练一个计算更快的模型，让它代替原模型完成部分预测？这就是这里要整理的代理模型思路。

​	不过，训练一个模型只是其中一步。更值得想清楚的是：**仿真样本怎么选、得到的数据是否可信，以及训练好的模型到底能用到哪里。**

​	本文围绕这些问题展开，重点介绍思路和数据设计，不涉及具体软件操作或代码实现。

## 2. 代理模型到底在代理什么？

### 2.1 从机理模型到代理模型

​	这里先区分两个概念。

​	机理模型通常从物理规律出发，描述输入与输出之间的关系。比如，根据材料本构关系、边界条件和控制方程，通过有限元计算得到工件的变形或应力。

​	代理模型则在指定的输入范围内，近似原模型的输入—输出关系。原模型输入一组工况后，需要经过数值求解才能得到结果；代理模型利用已有样本学习这种对应关系，再对新工况给出近似结果。

​	假设输入为工艺参数x，原仿真输出为 f(x}，代理模型可以写成：

$$
\hat{y}=\hat{f}(\mathbf{x})\approx f(\mathbf{x})
$$

​	这里的“近似”很重要。我们希望在满足误差要求的前提下，减少单次计算成本，而不是默认两个模型处处等价。

​	另外，**代理模型是一种用途，并不限定某一种算法。**高斯过程、径向基函数、神经网络等，都可以用来构建代理模型，不必把它直接等同于深度学习。

### 2.2 什么情况下值得用？

​	对于本文关注的仿真代理，比较典型的条件是：原仿真成本高、后续需要频繁调用，并且业务允许一定的近似误差。

​	它可以服务于以下任务：

- 实时预测：用较低的计算开销估计当前工况的输出。
- 参数优化：反复比较不同参数组合，筛选候选方案。
- 敏感性分析：分析输入变化对输出的影响。
- 不确定性分析：研究输入的不确定性如何影响输出。
- 数字孪生：作为其中的快速计算模块，为状态估计或预测提供支持。

​	这里也要算一笔账：生成样本、训练和验证都需要前期投入。如果后续只调用几次，建立代理模型未必划算。它的价值通常体现在后续的大量调用中，具体是否划算，还要结合实际成本判断。

## 3. 仿真与预测模型可以怎样结合？

​	整理了三种路径：

{% asset_img 1.png %}

​	图中三种路径分别对应直接替代、数据补充和模型级联，关键区别在于：最终模型学的是什么，仿真结果又用在了哪里。

### 3.1 直接替代仿真

​	流程是：仿真生成样本 → 训练代理模型 → 代理模型输出所需的仿真响应。

​	比如，输入工件尺寸、温度和载荷，输出某个区域的最大应力。这时，代理模型直接近似原仿真的输出，是比较典型的仿真替代。

​	注意，“替代”也可能只针对某个指标。原仿真能输出完整的时空场，并不意味着一个只预测最大应力的代理模型，也能给出完整应力场。

### 3.2 仿真数据辅助预测

​	流程是：仿真生成数据 → 与其他数据一起用于训练 → 输出目标预测结果。

​	如果仿真数据主要用于补充训练样本，而模型最终预测的目标并不是原仿真响应，那么更适合把它理解为仿真数据辅助建模或数据增强。

​	是否属于代理模型，要看模型实际近似的对象，不能只看训练数据中有没有仿真数据。

### 3.3 两阶段模型级联

​	流程是：仿真生成数据 → 训练代理模型 → 将代理输出与其他信息组合 → 训练下游预测模型。

​	比如，第一阶段快速估计工件截面形貌，第二阶段结合现场温度、尺寸等信息，预测最终产品的某个指标。

​	这样可以把原来计算较慢的仿真结果变成下游可调用的输入。但第一阶段存在的误差，也可能继续影响第二阶段，所以除了分别评估两个模型，还需要检查整个流程的最终误差。

### 3.4 补充：多保真代理模型

​	多保真可以与上面的路径结合，并不是与它们完全并列的第四种用途。

​	它的基本思路是：使用较多低成本、低保真数据了解整体变化，再通过少量高成本、高保真数据学习两者的差异，或进行联合建模。

​	比如，粗网格仿真成本较低，细网格仿真成本较高。如果两者对目标响应有可利用的关联，就有机会在控制成本的同时改善预测。

​	但不能默认“加一点高保真数据就一定更准”。不同保真度的输入、输出定义需要对应，低保真模型的偏差也需要评估。

## 4. 建立代理模型，会遇到哪些问题？

### 4.1 数据生成本身就很贵

​	仿真不是点击运行后就能得到可靠数据。几何建模、材料参数、边界条件、网格划分和求解设置，都需要投入。

​	如果每次仿真又很慢，那么“先收集足够多的数据再说”往往并不现实。这也是后面需要专门讨论采样设计的原因。

### 4.2 原仿真的简化会被带进代理模型

​	真实过程可能涉及热、力、组织演变等耦合，但原仿真可能只保留其中一部分。

​	如果被忽略的机制在目标工况下很重要，代理模型仅靠拟合这些仿真结果，通常无法补回缺失的物理关系。

​	注意，这不意味着代理模型只能处理单一物理场。问题的关键是原模型和训练信息是否覆盖了需要描述的机制。

### 4.3 拟合得像，不代表物理上合理

​	纯数据驱动模型不一定自动满足质量守恒、动量守恒、能量守恒或边界条件。在训练样本稀疏、边界复杂的地方，可能出现数值看似平滑、物理上却不合理的输出。

​	可以通过输出结构、物理约束或预测后的检查来减少这类问题，但应逐项验证，不能只看整体误差。

### 4.4 对仿真准确，不等于对现实准确

​	这里把两类误差分开：

- 代理误差：代理模型与原仿真之间的差异。
- 仿真与现实之间的误差：原仿真的物理假设、参数和数值设置等造成的偏差。

​	只用仿真结果作为监督信号时，模型主要学习如何复现仿真，不能据此保证它比原仿真更接近现实。

​	因此，如果引入现场数据进行校准，或者存在其他有效信息，模型相对现实的表现可能改变，不能把原仿真当成无条件的精度上限。

### 4.5 超出已验证范围，可靠性会下降

​	模型在已有样本附近表现较好，并不意味着它能处理新的极端工况。更容易忽略的是：每个输入都在各自范围内，也不代表这组多维参数组合已经被充分覆盖。

​	所以，代理模型交付时，除了模型文件，还应该有明确的适用范围和误差评价。

## 5. 只有 500 次仿真机会，工况怎么选？

​	假设单次有限元仿真需要 10 分钟，总共允许进行 500 次仿真。

​	这里是一个假设场景。按完全串行、每次耗时固定计算，求解时间约为 83.3 小时，还没有包括建模、失败重算和结果整理。

​	那么问题就变成：**怎样使用这 500 次机会，让模型在实际工作范围内尽可能可靠？**

{% asset_img 2.png %}

​	先确定有效工况，再采样、检查数据和训练；根据开发阶段的评估补充样本，最终使用独立测试进行验收。

### 5.1 先设计工况空间，再选择采样方法

​	首先要确定的，不是哪种采样算法最好，而是允许在哪个空间内采样。

1. **确定输入变量。**哪些变量会影响目标输出？哪些可以固定？有没有关键状态没有记录？
2. **确定取值范围。**范围应来自实际需求、设备能力和模型适用条件。
3. **明确变量关联。**有些参数会共同变化，不能随意独立组合。
4. **排除不可行组合。**满足单个变量上下限，不代表整体工况能够实现。
5. **确定重点区域。**常用工况、边界区域和高风险区域，可能需要不同的采样密度。

​	比如，温度和载荷分别都在允许区间内，但某一组合可能已经超出材料模型的适用范围。这样的点即使能被采样算法生成，也不应不加检查地投入计算。

### 5.2 常见采样方法分别解决什么问题？

​	普通随机采样可以作为基线，但在预算有限时，可能出现局部聚集和区域覆盖不足。不能简单说随机采样一定浪费，还是要结合维度、输入分布和目标任务判断。

**（1）LHS：先照顾每一个输入维度。**

​	拉丁超立方采样将每个变量的概率范围分成若干等概率区间，使每个区间都有样本落入。若变量服从均匀分布，对应的就是等宽区间。

​	它保证单个维度的分层覆盖，但不保证所有多维组合都覆盖得好。

**（2）Sobol：减少点集的不均匀分布。**

​	Sobol 是低差异序列，用于构造空间填充性较好的点集。它有助于减少局部聚集和空白，但不等于“保证所有多维区域都充分覆盖”，也不会自动识别哪些工况更重要。

**（3）Maximin：尽量拉开最近的两个样本。**

​	给定一组样本，先找到距离最近的两个点，再通过设计让这个最小距离尽可能大，目的是减少样本过度聚集。

​	这里需要先统一不同变量的尺度。否则，一个数值范围很大的变量可能主导距离计算，使其他变量的差异被掩盖。

​	Maximin 是一种设计准则，也可以与 LHS 等方法结合，并不是只能单独使用。

**（4）自适应采样：根据已有结果决定往哪里补。**

​	先用一部分样本建立初始模型，再根据评估结果选择新的仿真工况。常见依据包括预测不确定性、与已有样本的距离，以及特定任务下的改进潜力。

​	至于“哪里误差大就在哪里补”，需要注意：对于尚未仿真的新点，我们并不知道真实误差。只能利用已有验证结果或误差估计来指导，不能把未知误差当成已知条件。

### 5.3 自适应采样和参数优化有什么区别？

​	两者都可能反复选点，但选点的目的不一样。

​	如果目标是让模型在整个工作区域内更准确，会关注覆盖不足或不确定性较大的区域；如果目标是找到性能更好的工艺参数，则会重点考虑哪些点更可能改善目标值。

​	贝叶斯优化可以围绕目标改进来选点；遗传算法也可以用于搜索参数组合。但“找到较优参数”不代表“得到了全域都准确的代理模型”。

​	因此，选择方法前，先明确自己是在建模，还是在利用模型做优化。

### 5.4 预算还要留给验证和失败重算

​	500 次不应全部默认分给训练集。独立测试、必要的重复计算，以及自适应补样，都可能消耗预算。

​	具体比例要看问题维度、仿真失败率和精度目标，不能给所有任务套一个固定分配。

​	尤其注意：如果某批数据反复用于选择模型、调整参数或决定补样，它就参与了模型开发。最终测试应另行保留，避免用同一批结果既指导修改，又证明泛化能力。

## 6. 仿真完成了，不代表数据就准确

### 6.1 数值求解是否可靠？

​	检查网格、时间步长、收敛标准、求解警告，以及边界条件的数值施加是否正确。必要时进行网格或时间步敏感性检查。

​	求解器显示“完成”，只能说明流程结束，不能直接证明输出精度满足要求。

### 6.2 物理模型是否适用于当前工况？

​	比如，摩擦系数有没有依据，材料参数随温度变化的关系是否合理，忽略组织演变或其他耦合机制是否会影响目标输出。

​	这里要区分：数值上把设定的模型算对，与这个模型能否描述真实对象，是两个问题。

### 6.3 输出提取口径是否一致？

​	以“最大应力”为例，需要明确：

- 哪一种应力指标？
- 整个模型的最大值，还是特定区域的最大值？
- 某个时间点的最大值，还是整个过程的最大值？
- 单位、坐标和后处理方式是否一致？

​	如果这些定义混在一起，模型学到的标签就不再对应同一个问题。后续换更复杂的算法，也难以解决标签口径不一致。

​	整理数据时，最好同时保存输入、单位、模型设置、求解状态和提取规则，方便追溯异常样本。仿真失败的记录也应保留，不能直接把失败输出当成正常标签使用。

## 7. 怎样判断代理模型能用到哪里？

### 7.1 分开考察插值和外推

​	第一种情况是新工况位于已采样区域附近，主要考察插值能力。但即使每个变量都在训练范围内，新的参数组合也可能处于数据稀疏区，需要单独检查。

​	第二种情况是超出训练数据支持的区域，主要涉及外推。此时误差可能显著变化，不能因为模型给出了一个数值，就认为结果可用。

### 7.2 不同测试回答不同问题

| 测试方式       | 主要检查什么                                   |
| -------------- | ---------------------------------------------- |
| 随机独立工况   | 已定义工作区域内的一般预测表现                 |
| 参数边界工况   | 边界附近、极端但有效工况的表现                 |
| 工况区域留出   | 某个完整区域缺少训练数据时的表现               |
| 超出训练范围   | 外推风险，不能据此默认可用                     |
| 真实现场数据   | 从仿真到现实的适用性，需保证输入与输出口径可比 |
| 物理一致性检查 | 相关守恒关系、边界条件或趋势是否满足           |

​	区域留出比随机打散更有针对性。比如，把某个温度区间整体留出，才能观察模型对该区域的预测情况，而不是让训练样本始终紧挨着测试样本。

### 7.3 误差指标要对应使用目标

​	MAE、RMSE、R2 可以帮助描述整体拟合情况，但还应查看关键区域误差、较大误差，以及业务是否能接受。

​	比如，大多数工况预测准确，少数关键边界点偏差很大，平均误差仍可能很好看。对于接近零的输出，相对误差也可能不稳定，需要结合绝对误差理解。

​	如果代理模型用于参数优化，最终筛选出的候选方案还应回到高保真仿真，必要时通过实验确认。否则，优化算法有可能利用模型的误差，找到一个“预测很好、实际不好”的点。

​	实际使用时，也可以对超出已验证范围或不确定性较大的输入触发提示、补充仿真或回退原模型。这样的处理规则，应与模型一起确定。

## 8. 总结

​	代理模型的基本思路比较直接：用已有样本建立一个计算更快的近似模型，减少后续反复仿真的开销。

​	但它是否可靠，不能只靠训练误差判断。前面怎样定义工况、怎样安排有限的仿真预算、怎样检查标签，后面怎样验证边界和外推，都会影响最终结果。

​	这里最想保留的一点是：**代理模型学得像不像仿真，与它能不能用于真实任务，需要分别验证。**先把数据和使用边界讲清楚，再讨论模型结构，后续才更容易判断该改哪里。
