这是一篇示例文章，用来演示分类和标签的写法。

## 分类（categories）

分类是**层级结构**，用缩进的 `-` 表示父子关系。比如上面写了两个：

```yaml
categories:
  - 技术笔记   # 一级分类
  - Hexo       # 二级分类（属于「技术笔记」的子分类）
```

这篇文章会归到「技术笔记 → Hexo」这个分类下。

> 如果你只想用一个分类，就只写一行：
> ```yaml
> categories:
>   - 技术笔记
> ```

## 标签（tags）

标签是**并列结构**，一篇文章可以打多个，全部平铺列出：

```yaml
tags:
  - Hexo
  - 博客
  - 教程
```

这三个标签会分别出现在「标签」页，点击任意一个都能看到所有打了该标签的文章。

## 写在前面的话

以上就是最常用的分类和标签写法。它们的规则总结：

- **分类**：适合「大类目」，层级用缩进表达，一般 1~2 个
- **标签**：适合「关键词」，并列平铺，可以多个
- 分类和标签都**不用提前注册**，写完文章发布后自动生成
